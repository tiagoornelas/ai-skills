# Software Designing

Skill base para arquitetura e desenho de software.

## Propósito
Centralizar princípios estruturais, contratos de interface, divisão modular e modelagem técnica de sistemas.

## Contexto de Ativação
- Planejamento de arquitetura de novos projetos ou módulos.
- Definição de limites entre componentes, dependências e interfaces.
- Modelagem de dados, contratos de API e decisões arquiteturais (ADRs).
